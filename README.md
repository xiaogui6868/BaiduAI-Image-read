## 项目介绍
本项目基于百度AI开放平台实现智能图像物体识别，
使用Python + Flask搭建Web可视化网页应用，
通过浏览器即可上传图片完成智能识别，实时返回识别结果。

## 功能
- 网页端图片上传识别
- 可视化Web操作界面
- 实时展示AI识别结果
- 支持多格式图片（JPG/PNG等）

## 技术栈
- Python
- 百度AI 物体识别API
- Flask Web框架
- HTML 前端页面

## 运行说明
1. 安装依赖：pip install flask requests
2. 运行Python文件启动服务
3. 浏览器访问 127.0.0.1:5000 打开网页
4. 选择图片并点击上传，即可查看识别结果

## 项目说明
1.使用Flask搭建Web服务，实现网页版图像识别
